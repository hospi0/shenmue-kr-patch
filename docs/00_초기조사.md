## 대사 = SRF (EUC-JP)

## 실행 파일 1ST_READ.BIN (2,709,860 B, 세 장 공통)
- 메뉴·도움말·아이템 이름(한자+가타카나 읽기 쌍)·**메모장 문구**: 0x25C000~0x272000, `tools/exe_strings.py` → `work/exe_strings.tsv` (**포인터 기준 2,901 문자열 / 30,344자**, 잡음 몇 개 포함).
- 도움말은 `A`(한자판)/`B`(히라가나판) 앞글자 쌍, `0`(0x30) = 줄 구분.
- 포인터는 **0x0C010000 기준 절대 주소**(P0, 상위 8 없음) — 그 범위를 가리키는 워드 2,023개. 재배치 가능.
- 도움말 제어: `【제목】` 뒤 영문자(G/S/D/B/E/C…)가 서식 코드, `0`(0x30)=줄, `00`=빈 줄.
- **메모장** (문장 포인터 표 ≈ 0x27D1xx~0x281xxx, 줄 묶음 사이 0): 본문에 **2글자 사전 코드**가 박힌 압축.
  - 코드 글자 0-9·A-Z = 0~35, **사전 번호 = 첫×10 + 둘째 − 10** (첫 글자 ≥1). 사전 = **0x27CED0 포인터 표 159낱말**(0:芭月 … 25:さん 27:ている 118:チョウソンメイ 156:した 158:陶器屋ロシヤ).
  - 검산: 「14の仇は」→親父 · 「住谷35が」→住谷さん · 「（C8）」→チョウソンメイ · 「殺G6？」→殺した · 「何がC2んだ？」→あった · 「16を巻き込む」→福さん.
  - `0x` 꼴(01·02·03)은 사전이 아니라 줄 앞 제어(들여쓰기/이음)로 보임 — 미확정.
  - 한국어: 사전 낱말 뒤 조사 받침 문제 → 번역은 사전 코드를 «풀어 쓴» 문장으로 넣는 게 안전(문자열 재배치로 길이 해결). 사전 자체도 번역.
- 첫 0x28 바이트 = 파일 0x100~0x4000 을 0xAC004000 으로 복사하고 점프하는 스텁.
- `tools/sh4dis.py` (건버드2 것 이식, 적재 0x8C010000).
